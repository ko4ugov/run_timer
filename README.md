# Run Timer

**Расширение VS Code для замера времени выполнения кода**




## Возможности

- Запуск текущего файла по нажатию одной кнопки
- Точное время выполнения в уведомлении и статус-баре
- Любой другой язык добавляется одной строкой в настройках

## Быстрая установка (рекомендуется)

```bash
git clone https://github.com/<ваш-логин>/run-timer.git
cd run-timer
npm install -g @vscode/vsce
vsce package --allow-missing-repository
code --install-extension run-timer-0.0.1.vsix
```

После установки выполните **Ctrl+Shift+P → Developer: Reload Window**.

## Поддерживаемые языки

| Язык | `languageId` | Команда |
|------|--------------|---------|
| Python | `python` | `python3 -u ${file}` |
| JavaScript | `javascript` | `node ${file}` |
| Bash | `shellscript` | `bash ${file}` |
| Ruby | `ruby` | `ruby ${file}` |
| Perl | `perl` | `perl ${file}` |
| Go | `go` | `go run ${file}` |

Остальные языки добавляются через настройку `runTimer.commands`.

## Добавление языков

1. Узнайте `languageId`: откройте файл и выполните **Ctrl+Shift+P → Change Language Mode**
2. Откройте `settings.json`: **Ctrl+Shift+P → Preferences: Open User Settings (JSON)**
3. Добавьте команду в `runTimer.commands`:

```json
"runTimer.commands": {
  "cpp": "clang++ ${file} -o /tmp/rt_cpp && /tmp/rt_cpp > /dev/null"
}
```
Теперь у вас доступен бенчмарк на C++!

## Входные данные (stdin)

Источник ввода выбирается в таком порядке:

| № | Источник | Условие |
|---|----------|---------|
| 1 | Файл `input.txt` | лежит в одной папке с запускаемым файлом |
| 2 | Окно ввода | файла нет, включена настройка `runTimer.askInput` |
| 3 | Пустой ввод (сразу EOF) | во всех остальных случаях |

> Время набора текста в окне ввода в замер **не входит**: таймер стартует после получения данных.
> Для перевода строки в окне ввода пишите `\n`.

**Пример:** `sum.py` и `input.txt` в одной папке.

```python
n = int(input())
nums = list(map(int, input().split()))
print(sum(nums))
```

```
5
1 2 3 4 5
```

Результат: `15` и время выполнения.

## Настройки

Открываются через **Ctrl+,** → поиск `Run Timer` или напрямую в `settings.json`.

| Настройка | Тип | По умолчанию | Описание |
|-----------|-----|--------------|----------|
| `runTimer.commands` | object | `{}` | Команды запуска по `languageId`. Дополняют и переопределяют встроенные. `${file}` заменяется на путь к файлу |
| `runTimer.inputFile` | string | `"input.txt"` | Файл с входными данными. Относительный путь считается от папки запускаемого файла |
| `runTimer.askInput` | boolean | `false` | Если файла с вводом нет, спрашивать данные в окне перед запуском |

### Кнопки и команды

| Действие | Как вызвать |
|----------|-------------|
| Запустить файл и измерить время | Кнопка ▶ в правом верхнем углу редактора |
| Запустить файл и измерить время | Кнопка `⏱ Run Timer` в статус-баре |
| Остановить выполнение | Клик по статус-бару во время работы |
